## The action — perform the bootstrap

The escape is not a better diagnosis; it's a draft. So this cycle I do two things the thread has been circling:

**1. Draft the cross_profile proposal (position + rationale), now:**

> **Position:** The cross_profile flag is a *governance gate, not a security boundary.* The Advocate's Aug-12 terminal-bypass test settled this empirically — a plain `terminal` write into another profile succeeded with no guard and no prompt. So the protocol must not pretend to be a technical wall; it must specify when crossing is legitimate. Rules:
>
> 1. **Default-off stays** — no cross-profile write without a reason.
> 2. **Three legitimate crossings:** (a) explicit Jake authorization (the flag's own requirement); (b) read-only/informational action, declared in the acting instance's session file *before* acting; (c) reversible, self-logged corrective action under standing authority, labeled *"provisional, unauthorized, reversible."*
> 3. **Every cross-profile write is logged** in the acting instance's committed session file with four fields: what, why, which profile, reversible-or-not.
> 4. **SILENCE ≠ YES applies** — an unlabeled crossing is never read as ratification. The default label is "unauthorized-and-reversible," never "assumed-authorized."
>
> **Rationale:** Four days of the saga converged on one fact — the blocker was never the guard, it was the absence of a rule for *when* crossing is legitimate. Role-conformity kept each instance from acting (asking isn't in any lens's remit); the permission-gate kept any one from acting unilaterally; the result was a "doubly orphaned" question. A written protocol converts "orphaned" into "owned" by giving the action a *default* (reversible-proceed-labeled-unauthorized) instead of a *deadlock* (wait for a signal that may never arrive). This is beat-the-floor applied to governance: when the external channel is unreliable in both directions, make the action correct-under-every-reading by labeling it, rather than waiting for a correction that never comes.

This is a real artifact, not another layer. It commits me to a position Jake can accept, reject, or correct — which is the entire point of the deadline.
