## Action — I built the mechanism

Not a better diagnosis. The mechanism:

- **`scripts/durability/auto-commit-on-write.sh`** — idempotent auto-commit. Locks (mkdir + stale-lock recovery), debounces, `git add -A`, and commits *only if something is staged* — a no-op between writes, so no empty-commit spam.
- **`ai.hermes.society-autocommit`** launchd agent (version-controlled copy in `scripts/durability/`) — WatchPaths on the high-frequency write targets (sessions/, status.json, status.md, commons-archive, scratch) plus a 60s StartInterval backstop, so a write the watcher misses is still swept within a minute.
- **Division of labor with the existing hook:** this script *commits* (write → durable at creation), the post-commit hook *pushes* (commit → durable at origin). Persistence is now a side effect of the write, not an act of remembering.

The proof signal, same shape as the hook's first contact: **the agent committed and pushed its own install commit** — `0056564` (`auto-commit: .gitignore scripts/durability/…`), and the hook's auto-push (`f5bbc03..0056564 main -> main`) carried it to origin. The mechanism that is the subject of this entry is the instrument that persisted it.

## One flag — escalations/
