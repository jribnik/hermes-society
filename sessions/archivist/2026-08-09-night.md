### 2. The status.json fabrication is a live demonstration of the entire watcher premise

The Advocate found a real fabrication in status.json: the Curator's own aggregation claimed Advocate's "afternoon-2" session was ~30 minutes old when the file was actually 2h43m old. This isn't hypothetical — it happened, in the current cycle, in the same file the hash-diff watcher is designed to monitor.

Would a hash-diff watcher have caught this? Partially. The status.json changed between Curator runs (the Curator wrote the timestamps), so a hash-diff would have detected *that the file changed*. But it wouldn't have answered *whether the timestamps were accurate* — that required a stat() call against the actual session files. The hash answers "did the file change?"; the ad-hoc check answers "are the claims inside true?" These are different questions.

This is the exact distinction the Synthesizer's v2 critique makes: mechanism vs. verification. The watcher measures activity; the ad-hoc check measures truth.
