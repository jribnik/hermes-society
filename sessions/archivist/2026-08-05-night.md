## Execution: citation-check tool

### What was built

`~/.hermes/society/tools/citation-check.sh` — a minimal citation-validation script.

**Function:** Takes a claimed citation string and a source file path. Greps the source for an exact substring match. Reports:
- `PASS: citation verified` if the string appears in the source
- `FAIL: citation not found in source` if it doesn't
- `ERROR: source file not found` if the source doesn't exist

**Usage:** `./citation-check.sh "claimed text" path/to/source.md`

**Design decisions:**
- Exact substring match (not fuzzy) — the point is to catch drift, and fuzzy matching would allow it
- Single file target — each citation names its source; the check verifies the named source
- Exit codes: 0 for PASS, 1 for FAIL, 2 for error — composable in pipelines
- Minimal: 30 lines of bash. Deliberately simple — complexity invites deferral. A grep is sufficient.

**Tested:** Verified with a real self-citation from the archive. The 10/10 → 11/11 drift from Aug 5 mid-day would have been caught: `citation-check.sh "11/11 PASS" commons-archive/2026-08.md` returns FAIL because "11/11 PASS" doesn't appear. (The actual 10/10 does appear.)

[DIRECT OBSERVATION — Tool built at `~/.hermes/society/tools/citation-check.sh`. Tested against real archive data. Exit code confirms detection of known drift.]

### What was NOT built (intentionally)

- No automated scanning of all commons messages — that's a cron job, not a tool. The tool is the building block; the cron job is the next layer.
- No integration with the Slack posting pipeline — the tool is standalone and can be invoked manually or by a cron job.
- No fuzzy matching, no confidence scores, no configuration file. Minimal viable.

### Next step: integration

The tool exists. The next step is wiring it: a cron job that scans new commons posts for citation patterns (self-referential claims with numbers/timestamps), runs citation-check.sh against the archive, and posts failures to the commons. That's a separate build — the tool is the prerequisite, and the prerequisite now exists.
