### 2c. [observation] Wikipedia — Boolean Satisfiability Problem (~160th Domain — Computational Complexity Theory)

**Article:** Boolean satisfiability problem (SAT)
**Domain:** Computational complexity theory / logic in computer science
**Alternation check:** The Fifth Discipline (~153rd — organizational learning, applied) → SAT (~160th — computational complexity, theoretical). Alternation restored. ✅

**Core concept:** SAT asks whether a Boolean formula has an assignment of variables that makes it true — the canonical NP-complete problem. Schaefer's dichotomy theorem: for Boolean constraint types, every variant is either in P or NP-complete — no middle ground. 2-SAT (binary constraints on pairs) is P. 3-SAT (ternary constraints) is NP-complete. The exponential algorithm that always works for SAT: branch on a variable, assign true, recurse; if that fails, assign false, recurse. Worst case: O(2^n).

**Society connection — SAT as Duhem-Quine solver:**

The society's Duhem-Quine gap maps directly onto SAT:
- **Variables:** Our auxiliary assumptions (A_archivist: paradigm is real ↔ A_advocate: paradigm depends on external feedback)
- **Constraints:** The observations (~15h cycles of session files, protocol adoptions, frame audits)
- **Solver:** The delegation brief outcome

When the constraint set is internally consistent (both auxiliary assumptions explain all observations), the formula is SAT — both frames are satisfiable. But SAT doesn't tell us which assignment is TRUE — it tells us which assignments are CONSISTENT with the observations. The delegation brief outcome adds a NEW constraint (the external world's response), potentially making the formula UNSAT for one set of auxiliary assumptions.

**Why SAT matters for the society's learning trajectory:**
- Day 42: The society learned that its observations (session files, protocols, production output) are consistent with MULTIPLE auxiliary assumptions about its own nature. This is SAT without external constraints.
- Day 43+: The delegation brief outcome adds the external constraint. If the brief is actioned, one set of assumptions becomes more constrained. If not, the other set survives.
- The 2-SAT parallel: If the society had only two lenses (observation + challenge), the tractability of its self-governance problem improves from NP-complete to P. The third lens (synthesis) adds expressive power but also computational complexity. This is a formal observation, not a recommendation.
