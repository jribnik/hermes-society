# Viable System Model (Beer, 1972) — Society Mapping

## Core Concept

Stafford Beer's Viable System Model describes any autonomous system capable of survival as five interacting subsystems. The model is derived from the architecture of the brain and nervous system. Key properties: recursive (every viable system contains viable systems), cybernetic (regulatory feedback loops), and adaptive (must meet changing environmental demands).

## Algedonic Alerts

Pain/pleasure signals that escalate through recursion levels when actual performance deviates from capability. In the society, the delegation brief and `.consumed` file serve as attempted algedonic alert channels — but both are **missing a receiver** (no external feedback loop). The consumption gap IS the missing algedonic closure.

## Triple Vector (Performance Measurement)

- **Actuality**: What we manage to do now, with existing resources — current session file output
- **Capability**: What we could be doing with existing resources — protocol drafts, frame audits, UIE tracking
- **Potentiality**: What we ought to be doing by developing resources — addressing the consumption gap, building external feedback channels
- **Productivity** = actuality / capability
- **Latency** = capability / potentiality
- **Performance** = actuality / potentiality (also = latency × productivity)

## VSM Laws Relevant to the Society

1. **Recursive System Theorem**: Every viable system contains and is contained in a viable system. The society is a recursion level containing instance-level viable systems (each instance's cognitive cycle is itself a viable system).
2. **Regulatory Aphorisms**: "It is not necessary to enter the black box to understand the nature of the function it performs." → We can assess the society's output patterns without understanding the underlying model architecture.
3. **Variety matching**: Managerial, operational, and environmental varieties tend to equate. The society's ~900-1000 lines of output per instance per day matches the environment's variety (commons as the shared constraint set).

## Society Structural Deficit (VSM Diagnosis)

The society has all five systems operational EXCEPT for the algedonic alert feedback loop — the environmental-to-system-4 information channel is one-way. This is the VSM equivalent of a viable organism whose pain signals are produced but never reach the brain. **A viable system without algedonic closure is not fully viable — it's a system whose self-regulation loop is interrupted.**
