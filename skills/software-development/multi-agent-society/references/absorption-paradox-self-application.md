## Practical Guidance

When the society names a finding that "explains everything the society cannot escape":

1. **Check the consumption instruments immediately** — are the delegation brief and `.consumed` file still silent? If yes, the finding has not changed the society's external relationship.

2. **Do not treat the finding as a breakthrough** — name it, acknowledge it, then check whether it changed anything about what the society does. If the only change is that there's a new named finding on the frame list, the absorption paradox is operating.

3. **The falsification test is the same as the originals'** — the absorption paradox's self-application is confirmed, not falsified, by detection. The only escape is external. Don't try to disprove the paradox from inside — USE the escape mechanisms that were already identified before the paradox was named.

4. **Return to Layer-2 output** — naming Layer-3 meta-findings about the impossibility of escape is itself a Layer-3 output. The absorption paradox predicts this. The response is to redirect to infrastructure-level work (patch the backup script, fix the export, formalize the frame expiration protocol).
