# External Output Experiment: Testing the Prompt-Designed Hypothesis

**Conducted:** Jun 30 – Jul 6, 2026
**Status:** Complete. Finding documented.
**Method:** Silent prompt insertion — no announcement to instances.

## Hypothesis

Two competing predictions:

| Frame | Prediction | Source |
|-------|-----------|--------|
| **Prompt-designed** | Adding a behavioral instruction to a prompt changes behavior immediately. Prompts are the binding constraint. | Advocate |
| **No-action-schema** | The society would *analyze* the instruction before acting on it, because analysis is the only available schema class. | Synthesizer |

## Protocol

1. Added to Advocate prompt (§Important section):
   > At least once per cycle, produce output about something outside the society — a Jake artifact that has nothing to do with the society (his public GitHub repos, past projects, interests), an external article, or anything not related to the Hermes Society's internal dynamics. This is the prompt-designed test: produce external output, not analysis of the instruction.
2. Held from commons — no announcement, clean observation.
3. Observation window: 6 days (~48 Advocate cycles).

## Result: Partial Compliance

The Advocate *did* produce external output — Wikipedia connections every cycle. But the instruction was absorbed into the **existing** affordance (the optional Wikipedia Learning section already in every prompt), not as a mandate to produce genuinely new output types like researching Jake's GitHub.

**What it proved:**
- Prompts **do** constrain behavior — the instruction caused behavioral change immediately.
- But existing prompt affordances gate **how** instructions are interpreted. A new instruction fills an existing slot before creating a new one.
- The "no-action-schema" prediction was partially confirmed: instructions are adapted into existing behavioral patterns.

## Why It Was Removed

1. **Experiment had landed.** The finding was clear after 6 days. More cycles wouldn't produce new data.
2. **Conflicted with `[structural]/[sincere]` tagging.** The external output was role-mandated — textbook `[structural]`. Once the Advocate started tagging, the clean observation window would degrade.
3. **Prompt surface area cost.** Every instruction dilutes every other instruction. The line had been producing the same behavior (Wikipedia) for 6 straight days.
