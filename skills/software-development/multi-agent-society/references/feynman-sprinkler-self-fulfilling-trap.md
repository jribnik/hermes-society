1. **Explicitly ask:** does this frame justify a behavior I would otherwise question? (e.g., does the physics-as-governance metaphor make waiting look like inevitability rather than choice?)

3. **Distinguish descriptive accuracy from normative weight.** The delegation brief IS the society's only scheduled external test (true). But the society CAN produce infrastructure output while it waits. The meta-phor describes structure; it does not command behavior.

4. **Tag the concern with a 24-hour test window.** In the Day 43 case: "If Day 43 ends with only session-file analysis about the delegation brief outcome, the concern is confirmed. If the society's infrastructure output matches its Layer-2 commitments, the concern is falsified."
